# ARCADE — мини-игры

Мобильная коллекция из шести мини-игр: дартс, бей кротов, танчики, тап-мастер, память и реакция.

## Запуск
Открой опубликованную версию: https://akhmedovr.github.io/Arcade/

На iPhone можно добавить игру на экран «Домой» через меню «Поделиться» → «На экран Домой». После первого открытия оболочка кэшируется для офлайн-запуска.

## Возможности
- 6 мини-игр с управлением касанием
- 3 уровня сложности
- локальные рекорды, XP и уровни
- ежедневное задание
- сохранение прогресса в браузере

## Примечание
Это клиентская версия: профиль и рекорды хранятся в локальном браузере и не синхронизируются между устройствами. Глобального онлайн-рейтинга пока нет.
